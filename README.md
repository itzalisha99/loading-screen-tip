A make.fun bounty entry. The program writes one loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, to `/output/entry.txt`.

## The tip

> Tip: Stretch. Your agent already refactored the file you are afraid to touch.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, a single line, not only whitespace.
